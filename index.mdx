wolfBoot is a compact, memory-safe bootloader for embedded microcontrollers. It verifies firmware authenticity using industry-standard cryptography before handing off to your application — and provides a fail-safe mechanism to update firmware in the field without risking an unbootable device.

## Why wolfBoot

wolfBoot is designed for resource-constrained embedded systems where security cannot be compromised. It has no dynamic memory allocation, no standard C library dependency, and a minimalist HAL that makes porting straightforward.

## Get started in four steps

<Steps>
  <Step title="Clone and initialize submodules">
    ```bash
    git clone https://github.com/wolfSSL/wolfBoot.git
    cd wolfBoot
    git submodule update --init
    ```
  </Step>
  <Step title="Copy a target config and build key tools">
    ```bash
    cp config/examples/stm32h7.config .config
    make keytools
    ```
  </Step>
  <Step title="Build wolfBoot and sign the test application">
    ```bash
    make
    ```
    This generates keys, compiles the bootloader, compiles the test app, signs it, and creates the factory image.
  </Step>
  <Step title="Flash the factory image and confirm boot success in your app">
    ```c
    #include <wolfboot/wolfboot.h>

    // Call this after your application has verified it is working correctly
    wolfBoot_success();
    ```
  </Step>
</Steps>

<Note>
  wolfBoot supports Makefile and CMake build systems. See [Building wolfBoot](/building) for all options including IDE projects for Visual Studio and IAR.
</Note>
