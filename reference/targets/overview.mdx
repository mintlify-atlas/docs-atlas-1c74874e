wolfBoot supports more than 50 hardware targets spanning Cortex-M, Cortex-A, RISC-V, PowerPC, and x86-64 architectures. Each target has a dedicated HAL driver in `hal/` and one or more example configuration files in `config/examples/`.

## Simulated target

wolfBoot includes a **simulator target** (`TARGET=sim`) that runs on Linux or macOS as a native executable. It uses host files to emulate internal and optional external flash, enabling full firmware update cycle testing without hardware.

```bash
cp config/examples/sim.config .config
make
make test-sim-internal-flash-with-update

# Run wolfBoot and get version
./wolfboot.elf success get_version

# Trigger an update and verify version switch
./wolfboot.elf update_trigger
./wolfboot.elf success get_version
```

<Note>
The simulator is the recommended starting point for integrating wolfBoot into a new project before porting to real hardware.
</Note>
